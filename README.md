# MME Reorder Mapping

PMXエディタのプラグインです。

"現在のモデル" についてエフェクトを割り当てた MMEffect の割当ファイル (emm) の内容を、指定した "新しいモデル" 用に再マッピングした新しい割当ファイルを生成します。


## インストール

`MMEReorderMapping.dll` を PMXEditor のプラグイン・フォルダ（`_plugin/User`）にコピーしてください。


## 使い方

PMXエディタを開き、[編集] - [プラグイン] - [User] から [MME EMM再マップ] を選択します。

フォームが表示されますので、以下の項目を指定して 実行 ボタンをクリックします：

- 改造前PMX(任意): "現在のモデル" の PMX ファイルを指定します。空欄にした場合は PMXエディタで現在開いているモデルが対象となります。
- 入力EMM: "現在のモデル" に割り当てた MMEffect の割当ファイル (emm) を指定します。
- 改造後PMX: "新しいモデル" の PMX ファイルを指定します。
- 出力EMM: "新しいモデル" 用に再マッピングした MMEffect の割当ファイル (emm) を保存する場所を指定します。

いずれの入力欄もドラッグ＆ドロップでファイルを指定できます。


## 開発ガイド

Visual Studio でプロジェクトを開き、 libs フォルダに必要な DLL を配置してからビルドしてください。 詳細は [libs/README.md](libs/README.md) を参照してください。
