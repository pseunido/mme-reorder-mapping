# MME Reorder Mapping

PMXエディタのプラグインです。

"現在のモデル" についてエフェクトを割り当てた MMEffect の割当ファイル (emm) の内容を、指定した "新しいモデル" 用に再マッピングした新しい割当ファイルを生成します。


## インストール

`MMEReorderMapping.dll` を PMXEditor のプラグイン・フォルダ（`_plugin/User`）にコピーしてください。


## 使い方

PMXエディタを開き、[編集] - [プラグイン] - [User] から [MME EMM再マップ] を選択します。

フォームが表示されますので、以下の項目を指定して 実行 ボタンをクリックします。
ファイルの入力欄についてはいずれもドラッグ＆ドロップに対応しています。

### ファイル選択（標準モード）

- **ベースPMM(入力)**: 編集元となる MMD のプロジェクト・ファイル (pmm) を指定します。処理対象の割当ファイル (emm) は、この PMM に関連するものが選択されます。
- **ベースPMX(任意)**: "現在のモデル" の PMX ファイルを指定します。空欄にした場合は PMXエディタで現在開いているモデルが対象となります。
- **更新後PMX**: "新しいモデル" の PMX ファイルを指定します。

### ファイル選択（詳細モード）

「**表示**」を "詳細" にした場合は、次の項目が表示されます。

これらは標準モードの項目に応じて自動で入力されるため、それを変更したい場合に使用してください。自動入力される出力ファイル名については、元のファイル名に "_remapped" が付与されたファイル名になります。

- **ベースEMM**: "現在のモデル" に割り当てた MMEffect の割当ファイル (emm) を指定します。
- **出力PMM**: "新しいモデル" 用のプロジェクト・ファイル (pmm) を保存する場所を指定します。
- **出力EMM**: "新しいモデル" 用に再マッピングした MMEffect の割当ファイル (emm) を保存する場所を指定します。

### オプション選択

- **出力内のモデルパスを変更しない**: オンにした場合は、出力PMM および 出力EMM それぞれのデータ内部に記録されたモデルのファイルパスの情報を、"更新後PMX" のものではなく "ベースPMX" のものにします。これは、更新した PMXのファイル名を、更新前のファイル前のまま運用する場合に適しています。

### 実行

「**実行**」ボタンをクリックすると処理が開始され、 "更新後PMX" のファイルを使用するように設定された プロジェクト・ファイル (pmm)  と、それに対応する割当ファイル (emm) が生成されます。ファイル名はそれぞれ "出力PMM" および "出力EMM" の項目で指定されたものになります。


## 開発ガイド

Visual Studio でプロジェクトを開き、 libs フォルダに必要な DLL を配置してからビルドしてください。 詳細は [libs/README.md](libs/README.md) を参照してください。
